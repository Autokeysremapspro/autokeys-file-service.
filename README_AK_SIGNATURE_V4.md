# AK Cloud Signature V4

Renovación visual integral, sin modificar lógica de negocio, rutas, Supabase, pagos, pedidos ni servicios.

## Cambios
- Landing completamente nueva, cinematográfica y responsive.
- Sistema visual global V4: superficies, fondos, iluminación, tablas, formularios y estados.
- Sidebar y topbar con identidad AK Cloud.
- Animaciones suaves y compatibilidad con `prefers-reduced-motion`.
- Texto del sidebar actualizado al modelo de precio por archivo.
- Registro npm forzado al registro público.

## Instalación
Copiar todo el contenido sobre `autokeys-file-service`, hacer commit y push. En Vercel: Redeploy + Clear Build Cache.

No requiere SQL.
