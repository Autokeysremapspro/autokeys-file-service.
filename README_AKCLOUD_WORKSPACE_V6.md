# AK Cloud Workspace V6

Renovación visual e interactiva del portal basada en la versión V5.

## Cambios principales
- Shell vivo con spotlight dinámico siguiendo el cursor.
- Menú móvil real y navegación inferior específica.
- Paleta de comandos Ctrl/Cmd + K.
- Sidebar renovado con AK Intelligence y microinteracciones.
- Listado de trabajos reconstruido con vista tarjetas/compacta, progreso y estados.
- Ficha de pedido tipo workspace con pestañas Resumen, Versiones, Conversación e Historial.
- Garaje migrado al shell común.
- Sistema visual global V6 con superficies vivas, transiciones, iluminación y reduced motion.

## Seguridad funcional
No se modifican consultas de Supabase, rutas API, pagos, creación de pedidos, servicios ni lógica de negocio.
